# 🌡️ Burnout Barometer

**A color-shifting, interactive burnout self-assessment tool for all ages.**

Built with empathy-first design, the Burnout Barometer helps users across four life stages check in with their stress levels, get real feedback, and take one small step toward feeling better. As burnout increases, the entire app shifts from cool blues to deep reds — making emotional data feel intuitive and visual.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🌈 **Dynamic Color System** | The entire app shifts color in real time — cool blue when you're okay, warm red when you're burned out |
| 🌡️ **Live Thermometer** | Fills and updates as you move through the sliders |
| 👥 **Four Age Groups** | Distinct questions, language, stressors, and tone for each life stage |
| 🎨 **Mood Painting Canvas** | Free-draw or emoji-stamp your feelings (Ages 10–12) |
| 🗑️ **Trash It Board** | Write a worry and crumple it — tap to shred it (Ages 13–17) |
| 📌 **Goal Corkboard** | Pin up to 3 personal goals for the week (all ages) |
| 👀 **Age Group Compare** | See what stressors look like across all four groups |

---

## 👤 Age Groups

| Group | Focus Areas |
|---|---|
| **Ages 10–12** | Homework, overscheduling, people-pleasing, not enough downtime |
| **Ages 13–17** | Academic pressure, social media comparison, identity, sleep deprivation |
| **Ages 18–25** | Financial stress, career uncertainty, loneliness, purpose |
| **Ages 26+** | Work demands, caregiving, resentment, loss of personal identity |

## 🎨 Interactive Features by Age Group

### 🖌️ Mood Painting Canvas — Ages 10–12
No rules, no wrong answers. Kids can paint how they feel using:
- 12 paint colors
- Emoji stamps (😤 😭 😴 😊 ⭐ 💥 🌈 ❤️)
- Three brush sizes
- Touch-friendly — works on tablets and phones
- Clear button to start over

### 🗑️ Trash It Board — Ages 13–17
A cathartic release tool for teens:
- Type a stressor, worry, or thought you want to let go of
- Toss it onto the board — it crumples and lands at a random angle
- Tap any crumpled note to shred it with an animation
- Press Enter or click Toss It

### 📌 Goal Corkboard — All Ages
A simple commitment tool for every group:
- Type one thing you will do for yourself this week
- It gets pinned to a corkboard as a color-coded sticky note
- Each age group has its own note color
- Up to 3 goals per session
- Click ✕ on any note to remove it

## 🖥️ Tech

- Single self-contained HTML file — no frameworks, no dependencies
- Google Fonts: Fraunces + DM Sans
- Vanilla JavaScript with canvas API for painting
- CSS custom properties for the dynamic color system
- Fully responsive — works on mobile, tablet, and desktop
